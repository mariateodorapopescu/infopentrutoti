📚Ce sunt fișierele?

Definiție

Un fișier este o colecție omogenă de date, identificată prin nume.extensie. Fișierele ne permit să salvăm și să recuperăm informații în mod persistent.

În C++ lucrăm cu fișiere text sau binare. Noi ne vom concentra pe fișierele text, care sunt mai ușor de înțeles și manipulat.

🔧Etapele de lucru cu fișiere

1

📁 Crearea fișierelor

Primul pas este să creezi fișierele necesare. Un fișier deschis pentru citire trebuie să existe înainte de rularea programului, cu datele de intrare salvate în el.

📝 Exemplu fișier input.txt 
// Conținutul fișierului input.txt
10 20
Ana Maria
3.14
2

📚 Includerea bibliotecii

Include biblioteca <fstream> pentru lucrul cu fișiere.

#include <fstream>
// Dacă folosești și cin/cout, include și:
#include <iostream>
3

🔓 Deschiderea fișierului

Deschide fișierul în modul dorit: citire, scriere sau adăugare.

📖 Pentru citire

ifstream f("input.txt");
// sau
fstream f("input.txt", ios::in);

✍️ Pentru scriere

ofstream g("output.txt");
// sau
fstream g("output.txt", ios::out);

➕ Pentru adăugare

fstream h("data.txt", ios::app);
4

⚡ Prelucrarea datelor

Citește sau scrie datele în fișier folosind operatorii >> și <<.

💻 Operații cu fișiere 
// Citire din fișier
f >> a >> b;

// Scriere în fișier
g << "Rezultatul: " << suma << endl;

// Parcurgere fișier (număr necunoscut de valori)
while(f >> x) {
    // procesează x
}
5

🔒 Închiderea fișierului

Întotdeauna închide fișierele deschise pentru a elibera resursele.

f.close();
g.close();
h.close();

💡Exemple practice

📖 Exemplu: Citire și procesare

🔢 Suma numerelor din fișier 
#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ifstream input("numere.txt");
    ofstream output("rezultat.txt");
    
    int x, suma = 0;
    
    while(input >> x) {
        suma += x;
    }
    
    output << "Suma: " << suma;
    
    input.close();
    output.close();
    
    return 0;
}

📊 Exemplu: Statistici avansate

📈 Analiză completă date 
#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ifstream f("date.txt");
    ofstream g("statistici.txt");
    
    double x, suma = 0, minim = 1e9, maxim = -1e9;
    int count = 0;
    
    while(f >> x) {
        suma += x;
        count++;
        
        if(x < minim) minim = x;
        if(x > maxim) maxim = x;
    }
    
    g << "Statistici pentru " << count << " numere:\n";
    g << "Suma: " << suma << endl;
    g << "Media: " << suma / count << endl;
    g << "Minim: " << minim << endl;
    g << "Maxim: " << maxim << endl;
    
    f.close();
    g.close();
    
    return 0;
}
