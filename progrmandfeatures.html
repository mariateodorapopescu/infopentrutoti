Programs and Features

Programs and Features este instrumentul principal pentru gestionarea aplicațiilor instalate pe sistemul tău Windows. Te ajută să dezinstalezi, modifici și repari programele cu ușurință.

🗑️

Dezinstalare

Elimină complet programele nedorite din sistem

🔧

Modificare

Schimbă componentele programelor instalate

🔨

Reparare

Corectează fișierele corupte ale aplicațiilor

🚀 Cum să accesezi Programs and Features

Start → Control Panel → Programs → Programs and Features

📋 Operațiuni disponibile

1
Dezinstalarea unui program
Click pe programul dorit → selectează "Uninstall". Procesul va elimina complet aplicația și toate componentele acesteia.
2
Schimbarea unui program
Click pe program → selectează "Change". Poți adăuga/elimina funcționalități fără dezinstalare completă.
3
Repararea unui program
Click pe program → selectează "Repair". Restaurează fișierele corupte și setările originale.
Tip profesionist: Nu toate programele oferă toate opțiunile. Unele au doar "Uninstall", altele au "Uninstall/Change" sau "Change/Repair".
🔍

Indexing Options

Indexing Options îmbunătățește viteza căutărilor în Windows prin crearea unui index al fișierelor și conținutului acestora. Este ca și cum ai avea o bibliotecă cu un catalog complet!

Start → Search → "Indexing Options"

⚙️ Configurarea indexării

1
Vizualizarea statusului
În partea de sus vei vedea numărul obiectelor indexate și lista locațiilor incluse în index.
2
Adăugarea de locații
Click pe "Modify" → bifează drive-urile și dosarele dorite. Indexarea poate dura ceva timp pentru locații mari.
3
Setări avansate
În "Index Settings" poți indexa fișiere criptate și modifica diverse setări ale indexului.
⚡

Căutare rapidă

Găsește fișiere în secunde, nu minute

📄

Conținut indexat

Caută în textul din documente, nu doar în nume

🔄

Reconstruire

Rebuild indexul dacă întâmpini probleme

Atenție: Dacă anumite fișiere nu sunt indexate, verifică dacă extensia lor este inclusă în lista tipurilor de fișiere indexate.
🎯

Default Programs

Default Programs îți permite să controlezi cu ce aplicații se deschid diferite tipuri de fișiere. Imaginează-ti că ai mai multe chei pentru aceeași ușă - tu alegi care să fie principala!

Start → Default Programs

🎛️ Opțiuni disponibile

🎯

Programe implicite

Alege aplicațiile principale pentru browsing, email, etc.

📎

Asocieri fișiere

Conectează extensiile cu programele dorite

💿

AutoPlay

Configurează acțiunile pentru CD/DVD/USB

🌐

Acces programe

Controlează accesul la browsere și programele de email

🔗 Asocierea fișierelor cu programele

1
Accesează asocierile
Start → Default Programs → "Associate a file type or protocol with a program"
2
Selectează tipul de fișier
Click pe extensia dorită (ex: .jpg, .pdf, .mp3) din lista afișată
3
Alege programul
Click pe "Change Program" → selectează aplicația dorită sau caută cu "Browse"
Exemplu practic: Poți seta fișierele .jpg să se deschidă cu Photoshop, iar cele .png cu Paint - total personalizabil!
