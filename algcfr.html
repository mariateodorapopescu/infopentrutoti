Algoritmi cu Cifrele unui Număr

Descoperă secretele manipulării cifrelor - de la suma cifrelor la oglinditul unui număr și detectarea palindromilor!

Exemplu: 732848

732848
Suma:
7+3+2+8+4+8=32
Cifre:
6 cifre
Oglinditul:
848237

⚡Operații fundamentale

Acești algoritmi se bazează pe două expresii magice care ne permit să explorăm orice număr cifră cu cifră:

🎯 Ultima cifră

n % 10

Operatorul modulo (%) ne dă restul împărțirii la 10, care este întotdeauna ultima cifră a numărului.

Exemplu: 732848 % 10 = 8

✂️ Eliminare ultimă cifră

n / 10

Împărțirea întreagă la 10 elimină ultima cifră, lăsându-ne cu restul numărului.

Exemplu: 732848 / 10 = 73284

🧮Algoritmi clasici

1

Suma cifrelor unui număr

Pentru n=732848, suma cifrelor sale este 7+3+2+8+4+8=32

🔢 Algoritm Suma Cifre 
citește n
s = 0
cât timp n ≠ 0 execută
    c = n % 10    // aflăm ultima cifră
    s = s + c      // o adunăm la sumă
    n = n / 10     // eliminăm cifra procesată
scrie s

🎬 Execuția pas cu pas pentru n=732848:

1
n=732848, c=8, s=0+8=8, n=73284
2
n=73284, c=4, s=8+4=12, n=7328
3
n=7328, c=8, s=12+8=20, n=732
4
n=732, c=2, s=20+2=22, n=73
5
n=73, c=3, s=22+3=25, n=7
6
n=7, c=7, s=25+7=32, n=0 → STOP
2

Numărul de cifre ale unui număr

Pentru n=732848, numărul de cifre este 6

🔢 Algoritm Număr Cifre 
citește n
nr = 0
cât timp n ≠ 0 execută
    nr = nr + 1   // incrementăm contorul
    n = n / 10     // eliminăm ultima cifră
scrie nr
3

Oglinditul unui număr

Pentru n=732848, oglinditul său este 848237

🪞 Algoritm Oglinditul 
citește n
inv = 0
cât timp n ≠ 0 execută
    c = n % 10           // ultima cifră
    inv = inv * 10 + c    // adăugăm cifra la sfârșit
    n = n / 10           // eliminăm cifra procesată
scrie inv

🔍 Cum funcționează inv = inv * 10 + c?

inv = 0, c = 8 → inv = 0 * 10 + 8 = 8
inv = 8, c = 4 → inv = 8 * 10 + 4 = 84
inv = 84, c = 8 → inv = 84 * 10 + 8 = 848
inv = 848, c = 2 → inv = 848 * 10 + 2 = 8482
✨ Fiecare cifră nouă se adaugă la sfârșitul numărului!

🎯 Observație importantă: Palindromul

Un număr este palindrom dacă este egal cu oglinditul său. Exemple: 11, 121, 3, 36763, 12321

Test palindrom: dacă (n == oglinditul_lui_n) atunci "Palindrom!" altfel "Nu este palindrom"
