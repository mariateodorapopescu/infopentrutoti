💡Exemple practice

🔺 Calculul ipotenuzei

#include <iostream> #include <cmath> using namespace std; int main() { double a = 3, b = 4; double c = sqrt(pow(a, 2) + pow(b, 2)); cout << "Ipotenuza: " << c; return 0; }
Output: Ipotenuza: 5

🌊 Calculul unei unde sinusoidale

#include <iostream> #include <cmath> using namespace std; int main() { double angle = 30; // grade double radians = angle * M_PI / 180; cout << "sin(" << angle << "°) = " << sin(radians); return 0; }
Output: sin(30°) = 0.5

📈 Creștere exponențială

#include <iostream> #include <cmath> using namespace std; int main() { double principal = 1000; // suma inițială double rate = 0.05; // rata de 5% int years = 10; double amount = principal * exp(rate * years); cout << "După " << years << " ani: " << amount; return 0; }
Output: După 10 ani: 1648.72

🎯 Rotunjiri inteligente

#include <iostream> #include <cmath> using namespace std; int main() { double value = 3.7; cout << "Valoarea: " << value << endl; cout << "ceil(): " << ceil(value) << endl; cout << "floor(): " << floor(value) << endl; cout << "round(): " << round(value); return 0; }
Output:
Valoarea: 3.7
ceil(): 4
floor(): 3
round(): 4

💡 Tips pentru folosirea funcțiilor matematice

  • 🎯 Precizie: Folosește double în loc de float pentru calcule precise
  • 📐 Trigonometrie: Funcțiile trigonometrice lucrează în radiani, nu în grade
  • ⚠️ Erori: Verifică domeniile funcțiilor (ex: sqrt doar pentru numere pozitive)
  • 🔢 Constante: Folosește M_PI pentru π, M_E pentru numărul lui Euler
