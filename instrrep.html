🔍 While Loop - Cu test inițial

Bucla while verifică condiția înainte de fiecare execuție. Dacă condiția este falsă de la început, codul din buclă nu se va executa niciodată.

🔄 Sintaxa While 
while(conditie) {
    // instrucțiunile care se repetă
    // IMPORTANT: să modifici variabila din condiție!
}

✅ Do-While Loop - Cu test final

Bucla do-while execută codul cel puțin o dată, apoi verifică condiția. Este utilă când vrei să garantezi că o acțiune se întâmplă măcar o dată.

🔄 Sintaxa Do-While 
do {
    // instrucțiunile care se repetă
    // se execută ÎNTOTDEAUNA cel puțin o dată
} while(conditie);

⚡ Diferența cheie

  • While: Test ÎNAINTE - poate să nu se execute
  • Do-While: Test DUPĂ - se execută întotdeauna cel puțin o dată
  • Atenție: Nu uita punctul și virgula după while în do-while!

🔢 For Loop - Cu contor

Bucla for este perfectă când știi exact de câte ori vrei să repeți o acțiune. Are trei părți: inițializare, condiție și incrementare.

🔄 Sintaxa For 
for(expresie1; expresie2; expresie3) {
    // codul care se repetă
}

// expresie1: inițializare (ex: i=0)
// expresie2: condiție (ex: i<10)
// expresie3: incrementare (ex: i++)

🚀 Prima expresie

Dă contorului valoarea inițială. Poate conține mai multe inițializări separate prin virgulă.

🎯 A doua expresie

Condiție care verifică dacă contorul a ajuns la valoarea finală.

📈 A treia expresie

Crește sau descrește contorul. Poate conține mai multe instrucțiuni.

💡 Exemple practice

Să calculăm suma S = 2 + 4 + 6 + ... + 2*n cu diferite tipuri de bucle:

🔢 Varianta cu FOR clasică

s = 0;
for(i = 2; i <= 2*n; i = i+2)
    s = s + i;
✓ Clar și concis
✓ Variabilele sunt separate

⚡ Varianta cu FOR compactă

for(s=0, i=2; i<=2*n; s=s+i, i=i+2)
    ; // corpul buclei este gol!
✓ Foarte compact
✓ Totul într-o singură linie

📝 Note importante

  • Dacă secvența are cel puțin două subinstrucțiuni, acestea se grupează între {}
  • Instrucțiunea for are între () trei expresii separate prin ;
  • În varianta compactă, operațiunile sunt separate prin virgulă ,
  • Corpul buclei poate fi chiar gol dacă toată logica e în header
