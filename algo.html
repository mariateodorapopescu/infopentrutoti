📚Ce este un algoritm?

Definiție

Se numește algoritm o metodă generală de rezolvare a unei categorii de probleme.

Un algoritm este ca o rețetă de gătit - un set de instrucțiuni pas cu pas care, dacă sunt urmate corect, garantează obținerea rezultatului dorit. În programare, algoritmii sunt esența oricărei soluții software.

📦Variabilele - Cutiile de memorie

Variabilele sunt locații de memorie în care la un moment dat se rețin valori. Sunt ca niște cutii cu etichete care pot conține diferite tipuri de informații.

🏷️ Caracteristicile unei variabile

📝 Nume

Un șir de caractere format din cifre, litere sau "_" care identifică variabila

x, suma, numar_1, _temp

🎯 Tip

Mulțimea de valori de același fel din care face parte variabila

întregi, reale, caracter, logice

📍 Adresa de memorie

Locul din memoria calculatorului unde este reținută variabila

0x7fff5fbff6ac (baza 16)

🧮Expresiile - Calculele algoritmilor

Expresiile sunt combinații de variabile, constante și operatori specifici. Ele reprezintă calculele pe care le efectuează algoritmii.

🔢 Expresii aritmetice

Calculează valori numerice

a * b
(2 + 3) * 7
x + y - 5

🎯 Expresii logice

Au valoarea adevărat sau fals

a < b
x + 3 > 0
(x > 5) && (y < 10)

⚡Operatorii - Instrumentele de calcul

🔢 Operatori aritmetici

Pentru calculele matematice de bază

+ - * / %

🎯 Operatori relațională

Pentru comparații între valori

< > <= >= == !=

🧠 Operatori logici

Pentru operații cu valori logice

&& || !

📋 Tabela de adevăr

🔄 Relațiile lui De Morgan

!(p && q) = !p || !q
!(p || q) = !p && !q
