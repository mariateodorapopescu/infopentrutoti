📚Ce este limbajul pseudocod?

Definiție

Se numește limbaj pseudocod o metodă de reprezentare a algoritmilor care utilizează niște cuvinte cheie desprinse din limbajul natural.

Pseudocodul este ca o limbă universală pentru programatori - îți permite să exprimi logica unui algoritm fără să te împiedici în sintaxa specifică unui limbaj de programare. Este perfectul pentru:

🎯

Planificare

Structurează ideile înainte de a scrie cod

💬

Comunicare

Explică algoritmi fără bariere tehnice

🔄

Testare

Verifică logica înainte de implementare

🏗️Structurile de control

Limbajul pseudocod se bazează pe trei tipuri fundamentale de structuri de control:

1

Structura Liniară

Execuție secvențială

Cuprinde instrucțiuni de scriere, citire și atribuire executate în ordine:

📤 Scriere
scrie x, y, z scrie 3 scrie "info"
📥 Citire
citește variabila1, variabila2, ..., variabilan // a citi o variabilă înseamnă a solicita o valoare
📝 Atribuire
variabila ← expresie // "←" se citește "ia valoarea"
2

Structura Alternativă

Decizie bazată pe condiție

Execută una dintre două secvențe în funcție de o condiție:

Structura IF-THEN-ELSE
dacă condiția atunci secvența 1 altfel secvența 2 sfârșit dacă
🔄 Fluxul de execuție
Condiție
→
Adevărat
↓
Secvența 1
Fals
↓
Secvența 2
3

Structura Repetitivă

Execuție repetată

Trei variante pentru execuția repetată:

🔢 Cu număr cunoscut de pași (cu contor)
pentru c = vi până la vf cu pasul p execută secvența sfârșit pentru
🔍 Cu test inițial
cât timp condiția execută secvența sfârșit cât timp
✅ Cu test final
repetă secvența până când condiția

💡Exemple practice

📊 Exemplu: Modulul unui număr

Algoritm care citește un număr real x și determină modulul acestuia:

Algoritm Modul
citește x dacă x ≥ 0 atunci scrie x altfel scrie -x sfârșit dacă

🔢 Exemplu: Afișare cu contor

Afișează valorile 3, 8, 13, 18, 23, 28:

Algoritm Progresie
pentru i = 3 până la 28 cu pasul 5 execută scrie i sfârșit pentru // Rezultat: 3 8 13 18 23 28

⚠️ Note importante

  • Dacă p=1: pasul lipsește din sintaxă
  • Dacă p<0: atunci vi≥vf, în caz contrar instrucțiunea nu se execută
  • Test final: se execută cel puțin o dată
  • Test inițial: poate să nu se execute deloc
