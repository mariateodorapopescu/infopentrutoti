Determinarea primelor n valori

Învață să găsești primele n numere care îndeplinesc o proprietate specifică - un algoritm fundamental în programare!

Algoritm C++ 
for(int i = 0; count < n; i++) {
    if(hasProperty(i)) {
        cout << i << " ";
        count++;
    }
}

🎯 Cerința problemei

Să se determine primele n numere cu suma cifrelor pară.

Aceasta este o problemă clasică care ne învață cum să căutăm elemente care respectă o anumită condiție și să ne oprim după ce am găsit un număr specificat de elemente.

💡 Soluția explicată

Codul complet 
// Citim numărul de valori dorite
cin >> n;

// Inițializăm contorul și primul număr de verificat
nr = 0; 
x = 0; // primul număr cu suma cifrelor pară

do {
    // Calculăm suma cifrelor lui x
    s = 0; 
    y = x; // păstrăm valoarea originală
    
    while(y != 0) {
        s = s + y % 10; // adunăm ultima cifră
        y = y / 10;   // eliminăm ultima cifră
    }
    
    // Verificăm dacă suma este pară
    if(s % 2 == 0) {
        cout << x << " ";
        nr++; // incrementăm contorul
    }
    
    x++; // trecem la următorul număr
} while(nr < n); // continuăm până găsim n numere

🔍 Pas cu pas:

  1. Inițializare: Setăm contorul `nr = 0` și începem cu `x = 0`
  2. Bucla principală: Repetăm până găsim `n` numere valide
  3. Calculul sumei: Pentru fiecare `x`, calculăm suma cifrelor
  4. Verificarea: Dacă suma e pară, afișăm numărul și incrementăm contorul
  5. Continuarea: Trecem la următorul număr și repetăm
