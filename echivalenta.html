🔍While → Do-While

Transformarea unei bucle while (cu test inițial) într-o buclă do-while (cu test final) necesită atenție specială, deoarece bucla while poate să nu se execute deloc.

🔍 Bucla While originală 
while(conditie) {
    // secvența
}
⟷
TRANSFORMĂ
✅ Echivalentul Do-While 
if(conditie) {
    do {
        // secvența
    } while(conditie);
}

🎯 Pașii transformării

1 Testare preliminară: Adaugă un if pentru a verifica condiția înainte de a intra în bucla do-while
2 Corpul buclei: Copiază secvența din while în corpul do-while
3 Condiția finală: Pune aceeași condiție la sfârșitul buclei do-while

⚠️ Atenție!

Deoarece bucla while nu execută secvența când condiția este falsă de la început, este necesară testarea condiției suplimentar înainte de a scrie structura cu test final.

✅Do-While → While

Transformarea unei bucle do-while într-o buclă while este mai directă, dar trebuie să garantăm că secvența se execută cel puțin o dată.

✅ Bucla Do-While originală 
do {
    // secvența
} while(conditie);
⟷
TRANSFORMĂ
🔍 Echivalentul While 
// secvența (executată o dată)
while(conditie) {
    // secvența
}

🎯 Pașii transformării

1 Execuție inițială: Scrie secvența o dată înainte de bucla while
2 Bucla while: Creează bucla while cu aceeași condiție
3 Corpul buclei: Repetă aceeași secvență în corpul while-ului

💡 Important!

Deoarece bucla do-while execută secvența cel puțin o dată, este necesar să o scriem o dată în plus înainte de a scrie structura cu test inițial.

🔢For → While

Transformarea unei bucle for într-o buclă while implică separarea celor trei componente ale buclei for.

🔢 Bucla For originală 
for(init; conditie; increment) {
    // secvența
}
⟷
TRANSFORMĂ
🔍 Echivalentul While 
init;
while(conditie) {
    // secvența
    increment;
}

🎯 Pașii transformării

1 Inițializarea: Mută prima expresie (init) înainte de bucla while
2 Condiția: Folosește a doua expresie ca și condiție pentru while
3 Incrementarea: Adaugă a treia expresie la sfârșitul corpului buclei
4 Corpul: Păstrează secvența originală între inițializare și incrementare

💡 Exemplu practic

for(i=1; i<=10; i++) {
  cout << i;
}
→
i = 1;
while(i <= 10) {
  cout << i;
  i++;
}
